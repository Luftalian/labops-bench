# Terms

| Term | Meaning |
| --- | --- |
| Task / scenario | Versioned room, resource limits, workload, seed and execution assumptions |
| Job | A sample's predefined operation graph with dependencies and arrival time |
| Policy | AI agent, heuristic or algorithm producing configuration/scheduling decisions |
| Configuration candidate | A public equipment/layout option available equally to compared policies |
| Priority | Integer 0–1000; higher values rank feasible, unreserved work first |
| Makespan | Simulation time until all jobs complete their final arm unloading |
| AMR | Autonomous mobile robot represented by the transport model |
| External staging | Task-authorized storage of owned equipment outside the room |
| Replay | Playback or deterministic re-execution of recorded decisions, without fresh inference |
| Synthetic | A software/modeling assumption rather than an experimental measurement |
